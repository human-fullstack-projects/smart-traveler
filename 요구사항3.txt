
0. 코드의 난이도를 너무 높지 않게 세부적인 디테일요소 빼고 기능위주로 작성, 필수적인 예외처리 제외하고, 예외처리 작성하지 않기, 로그 빼기, 코드 수준은 개발경력 1년의 실력으로 작성, 핵심적 기능 위주로 작성 
1. /chat 경로 page에 관광지 찾아보기 칸 생성
2. 찾아보기 칸 클릭하면 db의 region 테이블의 full_name 컬럼 내용을 가져오게함
단, course 테이블의 destination 컬럼의 데이터와 같은 데이터만 가져오게 함
3. 찾아보기 칸의 지역 데이터를 클릭 하면, 선택한 지역 이름 정보가 채팅에 적용되도록 설정
4. 코스 추천 진입 시, 사용자에게 아래 질문을 넘기도록 수정
우리 일정을 알차게 짜보려면 몇 가지만 알려주세요:
어디로, 언제, 며칠 동안 가실 예정인가요?
누구와 함께 떠나시나요? (혼자, 친구, 연인, 가족?)
성인 몇명, 아동 몇명인가요?
이동할 때 대중교통과 자동차중 무엇을 이용하시나요?
5. 4번의 수정 내용을 RAG에서 처리해서 코스 추천 작업을 할 수 있도록 코드 수정
6. 추천 코스 내용을 사용자에게 보여준 후, 추천한 코스 정보를 사용자 id와 같이 db에 1번만 저장 하도록 수정
7. 로그인하지 않은 사용자(비회원)가 추천 코스 기능을 사용할 경우, 추천 코스 내용을 보여준 후, 해당 정보를 세션에 저장
8. 세션에 정보가 남아있는 상태에서 비회원이 회원가입 하고 로그인을 하면 세션의 코스 정보를 사용자 id와 같이 db에 1번만 저장 하도록 설정
- 7,8번 작업은 진행하기 전에 코드 전체 내용을 분석한 후, 어떻게 작업 할 지 자세한 설명을 한 이후에 재진행 여부를 묻는다.
- 이 때, 재진행하라, 진행하라 라는 명령어가 입력 되면 7,8번 작업을 진행한다.
