# 요구사항5 검토용 코스 1건

세종특별자치시를 선택했습니다. 기존 코스 1,005건에서 지역 ID 42, 지역 코드 36110, 세종이 포함된 목적지가 모두 0건이며, 이 지역에는 활성 장소가 16곳 있습니다. 아래 일정과 여행 조건은 검토용 예시이고 방문지 이름과 주소는 현재 DB의 `place`에서 가져왔습니다.

## 기존 코스와 공유하는 테마

대표 테마는 `HISTORY_CULTURE`(역사·문화 탐방)입니다. 현재 DB의 기존 RAG 코스 100건이 같은 코드와 이름을 사용합니다. 전의향교, 비암사, 연기대첩비공원을 중심으로 테마를 정하고, 둘째 날에는 호수와 정원 산책을 배치했습니다. 대표 테마는 `course.preferences_snapshot`에, 일차별 테마는 연결되는 `course_day.theme`에 저장하는 형식입니다.

## course 필드

| 필드 | 검토용 값 |
|---|---|
| title | 세종특별자치시 북부 유적과 호수·정원 1박 2일 |
| destination | 세종특별자치시 |
| region_id / region_code | 42 / 36110 |
| start_date / end_date | 2026-12-05 / 2026-12-06 |
| adults / children | 2 / 0 |
| companion_type / transport_type | COUPLE / CAR |
| generation_method_id | 2 (`user`, 수동 작성) |
| flow_type / status | COURSE_FIRST / done |
| member_no | 승인 후 `test001@test.com`에 부여되는 회원 ID |
| summary | 첫날은 전의향교, 비암사, 연기대첩비공원을 방문합니다. 둘째 날은 세종호수공원을 산책하고 국립세종수목원을 둘러봅니다. |
| preferences_snapshot | `{"theme_code":"HISTORY_CULTURE","theme_name":"역사·문화 탐방","travel_style":"relaxed","place_preference":"any","preferred_region":["도시"]}` |
| condition_meta | 아래 JSON 예시의 `itinerary` 구조를 사용합니다. |
| assumptions / fixed_events / tips | 각각 빈 JSON 배열 `[]` |
| is_active / share_consent / lock_version | 1 / 0 / 0 |

자동 생성 필드 `id`, `created_at`, `updated_at`은 DB 기본값을 사용합니다. 나머지 선택 필드는 NULL을 사용합니다.

## condition_meta 텍스트 예시

```json
{
  "seed_batch": "smart-traveler-rag-2000-v1",
  "itinerary": [
    {
      "day_no": 1,
      "visits": [
        {"seq": 1, "place_id": 127, "place_name": "전의향교", "place_type": "ATTRACTION", "address": "세종특별자치시 전의면 읍내리 149-1"},
        {"seq": 2, "place_id": 122, "place_name": "비암사(세종)", "place_type": "ATTRACTION", "address": "세종특별자치시 전의면 비암사길 137"},
        {"seq": 3, "place_id": 132, "place_name": "연기대첩비공원", "place_type": "ATTRACTION", "address": "세종특별자치시 연서면 도신고복로 586"}
      ]
    },
    {
      "day_no": 2,
      "visits": [
        {"seq": 1, "place_id": 128, "place_name": "세종호수공원", "place_type": "ATTRACTION", "address": "세종특별자치시 다솜로 216 (세종동)"},
        {"seq": 2, "place_id": 137, "place_name": "국립세종수목원", "place_type": "ATTRACTION", "address": "세종특별자치시 수목원로 136 (세종동)"}
      ]
    }
  ]

```

`smart-traveler-rag-2000-v1`은 새 2,000건을 위한 배치명 제안입니다. 현재 RAG 후보 조회는 기존 `smart-traveler-rag-1000-v1` 배치만 읽습니다. 새 배치의 코스를 검색에 포함하려면 후보 조회에 새 배치를 추가하고, 등록 시 위 방문 순서와 일치하는 `course_day` 2건을 함께 기록해야 합니다.
