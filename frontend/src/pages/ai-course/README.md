# 비회원 AI 대화 체험

- 메인·마이페이지·조건검색·AI추천코스의 공통 진입 검사는 App의 requestAiStart에서 처리한다.
- 비회원은 새 AI 대화를 1회 시작할 수 있다. 기존 대화의 후속 메시지·조건 수정은 계속 허용한다.
- 실제 일정 생성 기능은 아직 연결 전이므로 현재 사용 횟수 기준은 `/api/chat/sessions` 생성 성공이다. 이후 일정 생성 API 연결 시 차감 시점을 함께 옮겨야 한다.
- 두 번째 생성 시도는 회원가입·로그인 링크가 있는 안내창을 표시한다. 로그인 상태 확인 중이거나 확인에 실패한 경우 요청하지 않는다.
- 생성 실패는 사용 횟수를 차감하지 않는다. 브라우저 localStorage에 사용 여부를 보관해 내부 이동·새로고침·사이트 재방문 시에도 유지한다.
- 서버는 기존 guest_token의 대화와 HttpSession의 예약 상태를 검사한다. 동시에 여러 탭에서 요청해도 서버 세션당 하나만 생성하며, 트랜잭션 롤백 시 예약을 해제한다. 로그인 회원에게는 체험 제한을 적용하지 않는다.
- 비회원 식별 범위는 같은 브라우저 저장소와 서버 세션이다. 저장소와 쿠키를 모두 삭제하거나 다른 브라우저를 사용한 사람까지 동일인으로 식별하지는 않는다.
- 조건검색의 실제 추천은 기존과 같이 미연결 상태다. 공통 접근 제한만 적용하며 성공하지 않은 추천은 사용으로 기록하지 않는다.
