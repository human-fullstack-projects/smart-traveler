# Smart Travel 프런트엔드

기존 메인 목업을 React로 옮긴 독립적인 Vite 프런트엔드입니다. Spring Boot 서버 코드는 수정하지 않습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상을 설치한 뒤 이 디렉터리에서 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 `dist`에 생성합니다.

## 현재 구현 범위

- 메인페이지 대화 입력과 반응형 메뉴, 별도의 조건검색 화면을 제공합니다.
- AI·조건 추천·로그인·숙소·내 여행 페이지는 아직 서버와 연결되어 있지 않습니다. 입력은 현재 화면에서만 유지됩니다.
- 조건검색 이동은 `#/conditions`를 사용합니다. 기존 Spring Boot의 `/`는 Thymeleaf 화면이므로, 프로젝트에서 React를 기본 화면으로 제공하려면 배포 방식과 서버 라우팅 및 보안 설정을 별도로 연결해야 합니다.
