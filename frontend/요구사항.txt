사이드바 작업
0. 작성한 코드 난이도가 너무 높지않게 작성한다.
- 세부적인 디테일 요소를 다 빼고, 순수하게 기능 위주로 코드를 작성한다.
- 예외처리, 로그 관련 코드는 직접 요청하지 않으면 작성하지 않는다.
- 코드 수준은 경력 1년차 개발자 실력으로 작성한다.
- 핵심적 기능 위주로 작성하도록 한다.

1. 내 여행 일정 세부메뉴
- 예약 내용, 저장한 일정 클릭시 4개의 버튼(마이페이지, 내예약, 내코스, 내 휴먼추천코스)가 안보이게 설정하고 싶다.

2. 마이페이지 클릭하면 4개의 버튼(마이페이지, 내예약, 내코스, 내 휴먼추천코스)이 나오도록 하고 싶다.

3. 업주센터 버튼을 로그인 왼쪽 버튼으로 옮기고 싶다.

4. 숙소 찾기 클릭하면 나오는 업주센터, 여행 홈 버튼을 없애고 싶다.

5. 업주센터 버튼을 클릭하면 사이드바와 햄버거 버튼이 없고, 로그인 버튼 왼쪽에 고객 버튼을 만들어서 main으로 이동하게 하고 싶다
