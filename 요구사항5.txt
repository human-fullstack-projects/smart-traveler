course 테이블에 들어갈 코스 데이터 생성
0. course 테이블의 데이터에 사용되지 않은 지역 정보들을 정리할 것.
1. 0번 작업 결과의 한 지역 정보로만 코스 데이터를 1건 작성할 것. 단, 실제 데이터가 아닌 텍스트로 우선 작성할 것.
1-1. course 테이블 형식에 맞춰 작업 할 것.
1-2. place 정보를 사용해서 작업 할 것.
1-3. 코스는 course 테이블에 적용된 다른 코스들 같이 테마로 묶어서 작성할 수 있게 진행할 것.
2. 1번 작업 결과가 작성이 완료 되면 확인을 맡을 것.
3. 2번 내용이 통과되면 4번 작업을 수행할 것.
4. 4번 하위 항목을 참고하여 테스트 계정을 100개 추가 한다
4-1. 계정 이름은 test001~ 100의 으로 작성.
4-2. email은 test001@test.com 으로 001부터 100까지 작성
4-3. password는 123456 으로 작성
4-4. role_code는 여행자인 USER로 작성
5. 작성한 test001~100 까지의 계정으로 코스를 등록한다. 이를 SQL 파일로 작성해야한다.
5-1. 한 계정당 다양한 내용의 코스를 20개씩 작성해야 한다
5-2. 코스의 내용은 0번의 결과를 사용해 작성한다
5-3. 1-1, 1-2번의 작업 형식을 따라서 작성한다
5-4. 계정의 코스 내용의 중복이 없는지 검사해서 중복되지 않은 결과만 저장하고 중복된 코스는 재 작성하여 중복이 없을 때까지 작업한다.
