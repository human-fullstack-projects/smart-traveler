[다른 PC에서 smart_travel_db 복구 절차]

1. db-backups/smart_travel_db_20261116_164737.sql 파일을 새 PC로 복사

2. 기존 DB 삭제
mysql -u <계정> -p -e "DROP DATABASE IF EXISTS smart_travel_db;"

3. 백업 복구 (CREATE DATABASE 포함되어 있어 DB 미리 생성 불필요)
mysql -u <계정> -p < smart_travel_db_20261116_164737.sql

4. 확인
mysql -u <계정> -p -e "USE smart_travel_db; SHOW TABLES;"

※ 2번은 되돌릴 수 없으니 새 PC에 보존할 데이터가 없는지 먼저 확인할 것.
